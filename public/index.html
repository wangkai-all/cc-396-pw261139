Language reference

Restricted, side-effect free, no scripts

Values & operators

  • Numbers, "text", true/false, null
  • + - * / %, comparison == != < <= > >=
  • and or not, in (...), between a and b
  • x is null, x is not null
  • Missing values propagate SQL-style; use coalesce

Functions

  • lookup("dim", key) — read the pinned dimension version
  • if(c, a, b), coalesce(...), min_of/max_of
  • lower upper trim length concat substr startswith endswith contains
  • abs round floor ceil

Grouped mode

  • Group keys are any row expression, e.g. month = substr(order_date, 1, 7)
  • Outputs without aggregates are computed per row first
  • Aggregates: sum count min max avg count_distinct
  • An aggregate may reference another output, e.g. sum(net_amount_v1)
  • Sums are exact and independent of batch size
